# 1813 Unity Node Prototype

This repository now contains a Unity C# first-pass node-navigation prototype for:

- 1813: The Queenston Warning
- The Secret in the House

## Quick Start

1. Open this folder as a Unity project (Unity 6 or current LTS).
2. Open Assets/Scenes/Prototype.unity.
3. Press Play.

The prototype loads node route data from Assets/Resources/Data/nodes.csv.

## Milestone Scope

- Static-node route traversal only
- N/E/S/W view rotation
- Forward movement only on default/forward view
- CSV-driven node metadata display
- Placeholder visuals and placeholders for future richer systems
